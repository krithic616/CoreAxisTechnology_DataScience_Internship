# Task 2 — Unemployment Analysis with Python

CoreAxis Technology Data Science Internship — Task 2.

## Objective

Analyze unemployment trends using the dataset specified by CoreAxis Technology, clean and explore the data, visualize trends, investigate the impact of COVID-19, identify relevant patterns, and derive policy-relevant insights.

## Dataset

Source specified in the internship brief: Kaggle — `gokulrajkmv/unemployment-in-india`.

The dataset will be added to the `data/` directory when the project is prepared.

## Planned Workflow

1. Load and inspect the dataset.
2. Clean missing values and standardize data types and column names where required.
3. Perform exploratory data analysis.
4. Analyze unemployment trends over time and across regions.
5. Examine the COVID-19 period and changes in unemployment.
6. Investigate patterns and possible seasonality.
7. Create clear visualizations.
8. Summarize findings and policy-relevant insights.

## Structure

- `data/` — dataset files
- `notebooks/` — analysis notebook(s)
- `src/` — reusable Python code
- `visualizations/` — exported charts
